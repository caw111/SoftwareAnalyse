## 版本与引用说明

各文档保留原有版本和评审状态；本次合并整合文件与目录，不表示不同版本中的业务规则已经完成统一评审。

`docs/` 中的调研报告 v0.4 和需求规格说明书 v0.3 引用了“核心模块开发规范 SPEC v0.2”，但两个分支均未包含该文件。目前可用的是上方列出的 SPEC v0.1 会前评审稿及 Group1 的 Word 规范，不能将其视为所引用的 v0.2。

这些文档还引用了未随分支提交的 `academic_platform/` 实验报告、脚本与样本、`历史版本/` 备份及 `协作者内容/状态图说明.md`，相关链接仍需原作者补齐材料。仓库中已有的配套图示链接已调整为 `../images/`，已有的协作者 SPEC 链接已调整到 `docs/` 中的对应文件。
