# 需求调研和建模前期成果

本目录保存后续需求分析和设计仍会使用的基线与参考模型。业务规则以 SRS 为准，旧图仅供参考。

| 入口 | 用途 |
| --- | --- |
| [需求调研报告](docs/需求调研报告.md) | 角色任务、业务问题、数据源与小样本记录 |
| [SRS](docs/系统需求规格说明书_SRS.md) | 需求编号、权限、业务状态和验收场景 |
| [SPEC](docs/核心模块开发规范_SPEC.md) | 模块契约、数据处理与异常恢复规则 |
| [整理说明](docs/整合说明.md) | 基线优先级、旧图差异、材料状态与恢复方式 |
| [参考模型](image/) | 既有用例、活动、状态图及基线 Mermaid 源文本 |
| [保留清单](保留材料来源.json) | 整理前提交、原路径与 SHA256 |

新绘的核心业务类图和关键时序图见[需求分析交付目录](../需求分析/README.md)。PPT、重复提交包及构建缓存不在本目录中保留。
