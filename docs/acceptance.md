# 第一版需求追踪

本表区分实现和完整验收，不将演示数据当作真实采集，也不将模型设计当作已通过实现。基线见 `前期成果/需求分析/docs/需求分析验收场景.csv`。

| 分析场景 | 首版情况 | 证据 / 剩余部分 |
| --- | --- | --- |
| AN-AT-01 DOI 多来源、重复页 | 已实现结构化批次对应行为 | 幂等 requestKey、规范键、来源哈希与观测；事务测试 |
| AN-AT-02 同名与弱题名 | 部分 | 不自动合并；独立人物 ID；弱匹配候选复核队列未实现 |
| AN-AT-03 时间/编号/单位奖 | 已实现主要数据语义 | 保留日期精度、科学部编号类型、单位无个人名单；样例和测试 |
| AN-AT-04 分页失败恢复 | 后续 | 当前是有界 JSON 整批事务，没有联网分页检查点 |
| AN-AT-05 停止/执行尝试/重试耗尽 | 后续 | 不将结构化 import_task 等同完整 CrawlTask |
| AN-AT-06 入库后索引失败 | 后续架构 | 首版直接事务发布关系目录，无独立异步索引 |
| AN-AT-07 材料补充 | 已实现 | 材料版本递增、再次验证、未通过不授权；状态审计 |
| AN-AT-08 外部核验超时 | 后续 | 首版本地必要检查 + 人工证据审核，无外部 ORCID/邮箱核验 |
| AN-AT-09 并发终审/撤回 | 已实现并测试 | H2、PostgreSQL 两请求竞争；双 API 实例 HTTP 功能检查 |
| AN-AT-10 竞争门户/单人唯一 | 已实现并测试 | 用户与门户唯一约束；私有材料对象授权 |
| AN-AT-11 人物及同一关系机构 | 已实现并测试 | 用人物 ID 与其贡献的 institution_id 联合筛选 |
| AN-AT-12 非法参数/空/故障 | 已实现基础接口区分 | 400、200 空集、5xx 分开；HTTP 契约和 UI 错误提示 |
| AN-AT-13 同版分页/过期 | 部分 | 追加式版本固定且旧版保留，未来版 410；尚无版本到期回收 |
| AN-AT-14 去重统计/未知引用 | 已实现并测试 | 多机构分别去重，引用来源分组、已知覆盖率和 OA 未知值 |
| AN-AT-15 私有资料 | 已实现申请材料隔离 | P1 私人笔记尚未启用 |

补充已交付：Windows WPF 原生 GUI、Java 21 API、注册登录与科研身份人工审核、贡献认领和撤销、共著 BFS 最短路径及证据、容器构建、Compose 和 k3s/HPA 模板、服务器 k6 脚本。

明确的后续工作：

- 各真实数据源的许可登记、响应分类、解析器与小样本验证，再扩展采集量；当前真实数据集默认为空。
- 异步采集六状态、分页断点、执行租约、失败隔离和可靠后续发布登记。
- 公共题录纠错/软删除/归并治理、独立贡献附加说明、来源冲突审核、机构别名与分类版本管理。
- 真正的中文全文搜索和 BM25 相关度评估、多选条件、长期目录版本修订和回收。
- 时间桶热点、完整共著网络交互图、管理统计细化、完整后台分页。
- P1 推荐、私人专题库/笔记/导出；P2 订阅与 SSO。
- Windows 应用签名/安装器、.NET LTS 升级、生产密码重置与更完整的认证防滥用机制。
- 服务器冷启动与热缓存性能测量、HPA 实际扩缩容、数据库备份恢复演练、CodeArts 流程、覆盖率目标及人工清洗正确率抽样。

性能验收由用户决定在服务器执行。本次没有本地压力测试，没有将 1 万条模拟数据初始化或普通 API 耗时写成 P95 达标证据。
