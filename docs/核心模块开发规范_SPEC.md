# 学术成果检索与分享平台核心模块开发规范

**版本：v1.1｜日期：2026-10-10**

本规范规定四类成果的采集、清洗、去重、身份匹配、检索、认领、统计及质量管理规则，包括模块输入输出、处理过程、异常恢复和验收方法。

需求与用例见[SRS](系统需求规格说明书_SRS.md)，业务依据见[调研报告](需求调研报告.md)，来源与修订情况见[修订说明](整合说明.md)。算法参数和架构选型列为候选，采用前需完成固定样本测试和设计评审；性能要求为验收目标。

## 1 规范编号与共同契约

规范按九个模块编号，每项关联需求、模块输出和测试。早期五模块编号的对应关系保留，便于追踪。

| 规范编号 | 早期模块编号 | 对应需求 | 模块输出 |
| --- | --- | --- | --- |
| SPEC-INGEST-01 | SPEC-01 | FR-CRAWL、FR-SYNC、FR-INDEXREQ | 原文与来源、任务、处理及后续更新登记 |
| SPEC-DATA-01 | SPEC-02 | FR-CRAWL-004、FR-OUTCOME-004/007/008 | 规范字段、标识状态、质量标记 |
| SPEC-DATA-02 | SPEC-02 | FR-CRAWL-005/006、FR-OUTCOME-005 | 规范成果、来源映射、重复候选 |
| SPEC-DATA-03 | SPEC-02 | FR-SCHOLAR、SRS §6.2～6.3 | 独立人物／机构、候选与强标识关联 |
| SPEC-SEARCH-01 | SPEC-03 | FR-SEARCH、FR-ES、FR-OUTCOME-003 | 同版查询结果、分面、来源与状态 |
| SPEC-CLAIM-01 | SPEC-04 | FR-AUTH、FR-PORTAL、FR-INST、FR-INDEXREQ | 私有申请、审核历史和对象级有效授权 |
| SPEC-STAT-01 | SPEC-05 | FR-STAT、FR-INNOV、FR-REC | 统计快照、共著证据、最短路径；P1 推荐 |
| SPEC-QUALITY-01 | SPEC-02/05 和后台 | FR-ADMIN、FR-FEEDBACK、SRS §8.9 | 复核任务、质量报告、审计与恢复 |
| SPEC-TOOLS-01 | 原角色材料补充 | FR-TOOLS | P1 私人专题、笔记、比较和导出 |

关系数据库保存权威业务数据，检索索引可由其重建。内部成果 ID、来源 ID 和外部标识分别保存；账号、来源人物与门户管理权分别建模。原值、规范值、人工修订和来源证据均需保留。参与角色、日期含义和编号类型按成果类型解释。

每个处理结果记录 input_id、source_id、parser_version、rule_version、输出或错误状态及时间。错误至少区分非法输入、无权限、版本冲突、来源访问条件、来源超时、有效空结果、解析失败、质量隔离、待复核和公开版本失效。日志不得公开凭证、密码、私人笔记或完整认领证明。

## 2 SPEC-INGEST-01 数据采集与增量同步

### 2.1 目标和输入输出

接收来源、访问配置引用、成果类型、范围、时间窗口、游标／快照版本、频率和规则版本。输出原始内容版本、来源记录、采集观测、规范处理任务、处理状态及后续索引／统计更新登记。四类来源都应有独立适配契约；未验证的适配器不得以枚举存在声称已经接入。

Crossref 用于 DOI / ISSN 定向题录采集，OpenAlex API / 快照作为规模及主题数据候选，DBLP 作为计算机学科书目补充。专利、项目和获奖按具体公告来源接入。启用前登记访问方式、许可、频率、凭证、样本映射、时间及核验日期；配额、快照周期和接口状态按实际来源配置。

### 2.2 固定范围、幂等和检查点

1. 任务固定来源、范围、窗口开始和结束、配置及规则版本；Crossref 批量链路使用 cursor，不使用深页扫描。任务范围不是已确认学科。
2. 原始页写入后，事务持久化页内来源、原文引用、处理登记和下一页断点；提交成功才推进断点。原文件写入而事务失败可幂等重入，不能先推进游标后保存数据。
3. 来源稳定键与 raw_checksum 相同只新增观测／last_seen，不新增重复成果。checksum 变化保留新原文版本；原文未变但解析或规则升级仍允许重处理。
4. 已成功同步水位只在整个窗口规范处理、入库校验及后续更新登记可靠完成后推进；分页断点只表示任务恢复位置，不能代替成功水位。失败重跑窗口保持幂等。
5. 公告记录在一次采集中缺席时，不自动删除；撤销或字段变化需记录依据并复核。人工确认并锁定的字段遇到来源冲突时进入复核。

### 2.3 六状态与处理阶段

任务使用 PENDING、RUNNING、SUCCESS、FAILED、RETRYING、STOPPED，遵循 SRS §6.9 与 §13.3。SUCCESS 指有界采集、解析清洗、规范处理及可靠提交完成，允许有明确计数的隔离／待复核结果，不能有未记录的页面丢失。公开索引和统计版本另记结果。

采集、解析和规范处理分别记录阶段结果。规范处理记录可使用 PENDING、PROCESSING、COMMITTED、REVIEW_REQUIRED、QUARANTINED、ERROR，与 CrawlTask 的六状态分开。

请求级短重试与任务级重试分开，记录预算和下一执行时间。网络异常、429、5xx 在来源规则允许下有限退避；429 尊重来源等待说明。配置错误、访问条件问题和结构整体变化应停止盲目重试并保留 FAILED。重试耗尽保持 FAILED，管理员明确放弃才 STOPPED。

管理员 stop_requested 不等于立即退出。执行器在请求前、批次提交前检查停止请求和有效执行尝试；在安全边界停止，保留已提交批次。租约／执行尝试失效后，旧执行器不得新写数据或通过成功回调推进水位。成功或停止后的再次采集创建新任务关联旧任务。

### 2.4 配置与候选参数

| 配置 | 候选值 | 使用要求 |
| --- | --- | --- |
| 单请求超时 | 15秒 | 按来源试验确认，不是默认服务承诺 |
| 短重试 | 每页最多3次，退避1/2/4秒与抖动 | 与任务重试分别记数；来源等待要求优先 |
| 任务重试 | 最多3次 | 团队确认后配置，耗尽不自动再调度 |
| 解析失败阈值 | 5% | 待校准；明确分母、关键结构错误及允许隔离的范围 |

以上参数按来源测试后确定，并保存配置版本。

### 2.5 验收

覆盖停用来源、有效空页、200网页外壳、访问受限、异常页、有限重试、运行停止、旧执行器回调、事务中断及幂等重跑。成功后所有来源可追溯；失败不推进整窗水位；索引失败不使补采申请提前完成。对应 AC-R16/23/26～28、AC-U08/09。

## 3 SPEC-DATA-01 清洗与字段规范化

### 3.1 固定处理顺序

解析编码 → HTML实体解码与结构清理 → Unicode显示规范化 → 空白处理 → 字段校验 → 独立比较键 → 受控词表映射 → 质量标记。保存原文、展示值、比较值和规则版本，不原地覆盖来源。

| 对象 | 统一处理规则 | 异常与边界 |
| --- | --- | --- |
| 显示题名 | NFC、实体解码、连续空白压缩，保留语义符号 | 无题名隔离；不生成题名补原文 |
| 比较题名 | 独立字段宽度转换、casefold、有限弱标点规则 | 保留 C++ 等技术符号；不能任意删全部标点 |
| 摘要 | 解析器移除脚本／样式／标签，保留段落和许可 | 不允许展示则只标状态；不生成假摘要 |
| DOI | 去明确前缀／解析URL，trim、小写、格式校验 | 不任意删尾标点；格式、解析、元数据匹配是不同状态 |
| ORCID / ISSN | 标准分组、校验位，原值另存 | 格式正确不证明来源归属或账号控制 |
| ROR | 规范ID和完整引用，来源与机构层级保留 | 不将同域名多个机构自动并为一个 |
| 专利／项目编号 | text保留字母、前导零，按主管机构／资助体系规则解析 | 不用统一转整数或粗暴删符号处理各国号码 |
| 姓名 | raw_name、display_name、name_key、alias分开 | 保留中文与变音字符，拼音作别名；不改作者顺序 |
| 机构 | 原名、规范实体、别名、地域与有效期 | 历史署名不被当前任职覆盖；缺信息仅候选 |
| 日期 | 年／年月／日和值、精度、含义同时保存 | 不填造1月1日；来源发布日不是授权或资助日期 |
| 数值 | 引用分源非负整数与观察时刻 | 0为已知0，null为缺失；不跨源相加 |
| 词表 | 成果类型、奖励体系／等级、分类映射与版本 | 未分类单列；不把不同奖项等级换成价值评分 |

读取 OpenAlex 倒排摘要时，按词位置恢复文本，检查负位置、异常长度、位置重叠和空洞。接入时核对实际字段结构，重建摘要的展示范围遵守来源许可。

### 3.2 字段状态与隔离

known、missing、pending、not_applicable 分开。缺来源、未知类型、空题名不能创建公开成果；缺摘要、DOI、年份或机构可保留明确缺失的基础记录，但不计入相应完整样本。无贡献对象的记录保留待补；正式单位奖允许单位贡献对象，不强造个人。错误外部标识不进入精确索引和唯一键。

项目分别记录资助年、批准或立项年、计划起止和实际结题。奖励提名者与完成人分开，单位奖只建立单位贡献关系。Crossref 历史 subject 保留在原文中；默认分类使用平台目录、可用来源主题或经确认的候选标签。

### 3.3 验收

合法及非法标识、HTML、多语言、长题名、缺失日期、前导零、0与未知、单位奖、项目计划状态均须准备固定样本。抽样500条清洗正确率目标≥99%，覆盖率目标≥80%；统计输入、隔离、处理和公开数量，不能删除坏样本制造指标。对应 AC-R18～23、AC-U05/06。

## 4 SPEC-DATA-02 四类成果去重

### 4.1 一期可执行基线

| 对象 | 精确身份依据 | 候选及阻断 |
| --- | --- | --- |
| 论文 | 同来源稳定键；合法无冲突 DOI | 不同合法DOI阻断模糊合并；同DOI字段冲突不覆盖原主值；无DOI相似题名进入复核 |
| 专利公开文献 | authority + publication_number + kind_code | 申请公开与授权公告不合并文献；缺kind_code仅候选 |
| 专利申请／家族 | 申请按司法辖区+申请号；家族按有来源关系 | 家族不是公开文献或授权申请的等价唯一键 |
| 科研项目 | 资助机构+项目批准号，必要时包含计划范围 | 相同号码不同资助机构不合并；缺编号只人工复核；科学部编号与批准号分开 |
| 获奖 | 奖励体系+年度+来源项目编号；无编号用完整业务复合键核验 | 授奖机构、奖项、年度、类别等级、项目与对象必须相容；跨年度或明确等级冲突阻断 |

无 DOI 论文按题名指纹、年份和首作者键召回，避免全库两两比较。候选召回条件为：题名完全相同；三元组相似度≥0.75 且年份差≤1；或首作者比较键一致且题名词项 Jaccard≥0.60。以上条件需用标注集验证，召回后进入复核。

### 4.2 候选匹配评分

以下评分用于候选排序和人工复核。自动模糊合并默认关闭；启用前须通过标注集质量测试、强冲突检查及团队评审。

```text
S_paper = 0.55*S_title + 0.20*S_author + 0.10*S_year
        + 0.10*S_venue + 0.05*S_pages
候选自动区间 >=0.92；原复核区间 [0.82,0.92)

S_award = 0.50*S_project + 0.20*S_person + 0.15*S_org
        + 0.10*S_category + 0.05*S_year
候选自动区间 >=0.93；原复核区间 [0.84,0.93)
```

分量均在[0,1]；题名采用固定规则的字符三元组计数向量余弦，作者／人员／机构采用已确认实体集合 Jaccard。两空集合、空向量和缺失均是无证据，计算贡献0且不重分权重，记录null。匹配分数表示相似度，不代表身份一致的概率。

论文年份同年1、差一年0.5、差更大0；出版物与页码／文章号经确认相同1，冲突0，未知贡献0。将来启用自动区间也须具备题名、非空作者、年份、出版物四项证据且无硬冲突。只有相同题名最多贡献0.55，不能归一化成1。预印本与正式版本可建立版本关系，不直接吞并。

奖励项目名按题名规则，人物及单位按集合；类别与等级都同为1，仅一同为0.5，皆异为0；同年度为1。授奖机构、奖项体系、年份与等级硬冲突优先于高分。正式单位奖的个人分量可不适用，不重分权重，必要时人工确认。

分数低于原复核区间但题名高度相似、标识冲突或证据缺失，仍可按明确原因进入复核，不能仅因低分宣称已经确定不同实体。A像B、B像C不能推断整簇同一；每次加入检查全部强标识及相容性，冲突或无法确认则人工处理。

### 4.3 合并输出及恢复

同一事务写规范成果、有效来源映射、字段主值依据、贡献和机构关系、旧实体 merged_into_id、规则版本、分量／阻断及审计。原raw版本不删除。旧公开链接可解析，私人收藏迁移规范ID并按同库唯一键去重，笔记权限不扩大。

回退先核对来源映射、关系变更及后续修订，必要时人工重放，不能盲目恢复旧表覆盖有效新编辑。重复执行同输入和规则不新增相同成果。自动规则启用后准确率目标≥98%，同时报告候选召回与漏合并，自动合并准确率与总体去重效果分别报告。

## 5 SPEC-DATA-03 人员与机构消歧

### 5.1 身份层次和一期规则

ORCID区分syntax_valid（格式）、source_asserted（可信来源人物关联）、authenticated_control（申请人认证控制证据）。格式合法或手填iD不证明账号控制。来源ORCID无冲突时可关联作者实体，冲突于已核实身份则复核；任何来源匹配都不直接授予门户管理权。

无可靠强标识保持来源级或独立人物，姓名、机构、共同作者与主题生成候选。中文常见同名和两个不同已确认ORCID不自动合并；机构变动携带时间，不单凭任职不同判为不同人。待合并作者不能在同一批互相充当已确认共同作者证据。

### 5.2 人员匹配候选评分

```text
S_author = 0.30*S_name + 0.25*S_affiliation + 0.25*S_coauthor
         + 0.15*S_topic + 0.05*S_time
原候选自动区间 >=0.95；原复核区间 [0.85,0.95)
```

本期弱标识作者评分仅用于候选复核，自动开关默认关闭，遵守 SRS §6.2。姓名比较用已确认别名或固定字符规则；机构采用时间可比记录中的机构ID集合；共同作者仅用已确认ID；主题使用固定分类／词项向量；时间用已知成果年份区间交并比，都是弱证据。缺失贡献0，不重分权重。单独同名最多0.30不能自动合并。

### 5.3 机构规范化

可信无冲突ROR精确关联；缺ROR时规范名、别名、国家、城市、域名只作候选，最终人工确认。学校与院系层级保留，明确汇总上级的范围。更名保留别名有效期；机构合并／拆分存历史关系，不改写旧成果机构。人物当前机构与署名机构分开。

测试覆盖同名不同人、同人不同名、任职变化、不同 ORCID、共享域名及机构历史。来源作者自动关联准确率目标≥97%，ROR 精确映射抽样准确率目标≥99%；未启用的弱标识规则不计入自动关联测试结果。

## 6 SPEC-SEARCH-01 检索与排序

### 6.1 输入与查询语义

请求包括 query、type、人物ID、person_mode=all/any、机构ID、author_scope=same_contribution/any_contribution、领域与子领域开关、年份或类型专属日期、来源／模拟筛选、sort、page/page_size及数据版本。默认page_size=10，最大100。起年晚于终年、非法字段、越界页和类型不适用分别说明。

姓名先检索候选，用户确认后以ID查询。跨维度AND，同维度多选OR；all/any明示。指定人的机构条件必须属于同一贡献关系，不能用两个独立数组交叉匹配。综合类型查询按类型解释时间，机构默认采用成果发生时关系。

精确合法DOI、公开号、项目编号优先定位相应类型；项目编号结合资助机构，机构或批准计划歧义先提示。ORCID定位人物、ROR定位机构；这不是认领身份核验。无关键词且有筛选允许浏览，完全空条件按明确的最新收录顺序。

### 6.2 默认排序与调优参数

一期默认按文本相关度排序，BM25 字段权重的基准候选为 title^4、author_names^2.5、venue_name^2、abstract^1、discipline_labels^2。DOI 优先精确定位，DOI^6 保留为测试候选。参数采用前需记录查询集、测试结果和评审版本。

并列按业务年份降序、规范成果ID升序；未知年份置后。用户选择日期排序时按声明日期再相关度和ID；引用排序固定同一来源观察，缺失置后。适用日期字段不混用。

以下按成果类型设置的权重用于对照调优，与上述 BM25 候选分别测试：

| 类型 | 文本权重候选 |
| --- | --- |
| 论文 | 题名0.45、摘要0.20、关键词0.15、作者0.10、出版源0.05、机构0.05 |
| 专利 | 题名0.40、摘要0.25、申请人0.15、发明人0.10、CPC0.10 |
| 奖励 | 项目名0.45、完成人0.20、完成单位0.15、奖名0.10、类别等级0.10 |
| 项目 | 标题优先，项目号精确；负责人、资助机构、类别权重须另校准，不自拟未验证公式 |

论文复合排序候选为 Score=0.80×R_text+0.10×R_citation+0.05×R_recency+0.05×R_quality。启用前需确定分量归一化、领域与年份范围、来源、缺失处理及对照测试。被引量与 BM25 原始分不能直接相加；归一化须覆盖实际排序集合，仅在返回页计算会破坏全库排名。

all 类型默认按成果类型分组，或采用经校准的共同排序规则。不同索引的原始得分须经校准后比较；未启用复合公式时，使用文本相关度排序。

### 6.3 索引与公开版本

每规范成果一份索引文档，ID为成果ID；人物与机构有实体键，贡献关系使用能保留“同人同机构”语义的结构。分类树、规则、数据范围、索引和统计构建版本一致。业务变更可靠登记更新工作，失败可重建；不得在数据库提交而任务登记丢失后仍宣称更新成功。

候选发布流程为固定业务快照 → 构建索引与统计 → 验证计数、标识、来源和样例 → 标记READY → 短事务切换公开版本指针。请求固定release，详情和统计明细读取同版；保留旧版覆盖令牌有效期，失效返回410或对应可解释错误。权限实时校验，不因旧快照恢复已撤销授权。

### 6.4 验收

至少50组查询含人物确认、多作者、同贡献机构、四类专属字段、空条件、错误年份、不适用筛选、精确命中与无命中、缺失状态及稳定分页。G1-AT-01～24和AC-U01/02/11采用固定模拟集合手算。至少10,000条、20并发、预热5分钟目标P95≤2秒，详情≤1秒，记录环境和错误率。

## 7 SPEC-CLAIM-01 身份、门户和成果管理

### 7.1 申请契约与材料

申请人、对象、申请类型、材料版本、证据、状态、审核占用及到期、提交／处理／撤回时刻、审核人／意见、旧申请关联分别记录。身份申请、门户管理权和具体成果贡献为不同对象。邮箱控制、认证ORCID、公开机构页和代表作是组合证据候选；手填标识及同名不必然通过。课程模拟证据必须标注。

材料默认私有；仅本人和授权审核人员访问。上传验证大小和类型；来源URL只存证据，后端访问需受控采集，不直接获取任意用户地址。不默认采集身份证扫描件。

### 7.2 统一状态

门户认领使用 SRS §6.8 的完整模型：DRAFT → PENDING_VERIFICATION → VERIFYING → PENDING_REVIEW → UNDER_REVIEW → APPROVED / REJECTED / NEED_MORE_INFO；未终审时可撤回为 WITHDRAWN。验证服务暂不可用时保持待验证或转人工核验，补充材料递增版本，审核占用超时回待审。页面上的“待审核”是显示摘要，不另设状态转换。

REJECTED、WITHDRAWN和APPROVED保留终态历史，再申请新编号关联旧申请。通过后的解绑和贡献撤销是新业务，不回退原批准申请。审核、补充、撤回并发校验版本，只能有一个合法提交。

### 7.3 原子授权与维护边界

一账号最多一个本人门户，一门户最多一个有效管理账号。通过时锁定或原子校验对象、申请版本、有效绑定，状态、授权和审计在同一事务提交。竞争冲突返回409或等价业务结果并回待复核，不替换已有合法权限。

多人贡献成果可各有一条有效确认关系；同人同成果最多一条。个人可维护本人说明、标签及顺序，公共题录、作者顺序、机构、归属和合并必须审核。撤销只处理申请人的有效关系，保留公共成果和其他人关系。

论文缺失转经审核的定向补采；非论文补录先查精确键及候选，再发布新记录或关联已有记录。审核通过不是采集或发布完成；索引补采仅检索可见时完成。机构注册、身份申请及科研人员索引申请沿用SRS契约，私人申请明细不向他人公开。

### 7.4 验收

覆盖材料缺失、暂时验证失败、重复本人申请、他人竞争、并发审核／撤回、终态再申请、同一账号第二门户、越权字段、多人贡献撤销、补录重复及补采索引失败。对应AC-R02～06/15/17/24/25/29、AC-U10。

## 8 SPEC-STAT-01 统计、合作网络与推荐

### 8.1 统计集合与口径

所有指标先固定公开数据版本、成果类型、领域、机构、业务时间及真实／模拟范围，按规范身份去重。排除未审核草稿、被合并旧实体和软删除；公开标注撤稿是否排除由显式条件控制。整体成果按类型身份计数，授权专利按申请实体，文献和家族另外命名。

机构按成果发生时关系全计数，同成果同机构一次；机构合计可大于全库总量。当前成员视图另设；领域多标签同理，多领域合计不等于全库。排名数量相同并列，稳定次序机构ID，不称科研质量排名。

论文使用选定出版日期（统一默认print、再online、再issued）；专利授权年度、项目资助年度、奖励年度分别计算；项目立项可另切维度，不用网页发布时间补成果时间。未知年份单列，月／日分析仅纳入相应精度，未结束年显示截至时间。

引用次数按同一来源的有效值汇总，缺失与 0 分开，并显示覆盖率。OA 的已开放、未开放和未知分别统计，注明分母；请求失败记为未知。热点频次按时间桶统计包含主题的不同成果，一项成果同词只计一次，占比以有效分析语料为分母。频次趋势与预测功能分别定义；分母为 0 时不显示百分比。

### 8.2 共著与最短路径

节点为可识别学者，边为所选有效论文的共同署名，边权等于不同共同论文数量；多人论文为每对作者各增一次，重复来源不增权。引用、共同机构和推荐关系都不生成共著边。

FR-INNOV-001用未截断可用图计算最少边数路径，候选实现BFS；起终点相同返回0边，多个等长路径返回按学者ID稳定选择的一条并说明，无路径表述为“当前范围未找到”。图受规模或超时限制时返回未完成或范围受限，不伪造无路径结论。每条路径边附证据成果和同版筛选。

路径验收采用人工构造图，覆盖等长路径、孤立点、仅引用但无共著、重复论文、过滤断边和节点截断。逐边核对共同论文是否属于当前范围，基础网络与路径功能分别验收。

### 8.3 P1 相关论文推荐

推荐候选来自内容相似、有依据的主题或出版物匹配。按规范成果 ID 去重并排除当前论文，默认 8 篇、最大 20 篇；每条附至少一个有证据的推荐理由。同出版物不等于同学科；摘要或标签缺失时使用 title、venue 和 year，无候选时返回空结果。建议等待上限为 1 秒，超时不阻塞主详情。

推荐排序及参数需单独版本和测试；行为个性化和潜在合作者推荐属于P2，不默认使用私人历史。该P1能力不替代本规范的路径创新。

### 8.4 更新与验收

统计从同一版本的成果与关系中，按全库或声明范围聚合；校验后切换快照。失败时保留旧快照，重试不重复累加。本人管理状态、公开产出和管理员质量统计分别展示与授权，统计结果可打开同条件、同版本的明细。

按SRS §6.4两论文样例和G1-AT-15～22验证总体、机构、领域、引用、OA及网络。至少10,000条、20并发预热5分钟，基础预聚合统计P95目标≤3秒；记录实际环境、范围和版本。

## 9 SPEC-QUALITY-01 质量、人工复核与审计

复核类型覆盖论文／奖励重复、缺编号项目、作者／机构候选、强标识或字段冲突、认领归属纠错、来源结构与缺失。页面同时展示原字段、规范字段、来源、时刻、标识、分量、缺失、阻断及版本；支持合并、保持独立、版本关系、等待证据或字段修订。

复核提交携带任务版本和理由，过时任务返回冲突。复核决定、成果与关系变更、字段修订及审计在同一事务保存。人工锁定字段优先，来源新冲突进入复核；仅相同来源、相同语义的字段可按有效更新时间取主值。

质量报告按来源和类型列输入、可解析、规范处理、隔离、待复核、公开、字段完整、未分类、机构未匹配及失败数量。完整率分母包含适用记录和缺失项，不跨来源借用补充样本提高原来源指标。异常状态覆盖与实际解决率分别命名。

质量目标按 SRS §8.9 执行：核心字段完整率≥95%，来源追踪率100%，清洗抽样正确率≥99%，自动去重准确率≥98%，作者自动关联准确率≥97%，ROR 抽样准确率≥99%，异常状态覆盖率≥95%。测试报告注明样本量、分层、标注依据、算法版本及实际结果。

## 10 SPEC-TOOLS-01 私人科研资料能力 P1

收藏、专题和笔记按 account_id 授权，收藏唯一键为账号、专题和规范成果 ID。成果合并时迁移引用并去重，笔记仍按原权限访问。笔记记录方法、条件、局限、资源版本及原文位置；保存失败时保留待保存内容，并提示状态。

导出范围为用户确认的集合或筛选快照，跨页选择须完整，文件注明数量、格式、版本、来源和缺失字段。CSV / BibTeX 导出处理文本被误解析为公式的风险。比较限定 2 至 10 篇论文，展示条件差异；研究创新性由用户判断。外链显示访问状态和来源，实验复现需另行验证。

私人检索保存与关注不默认触发通知。订阅和学术讨论P2需另定义权限、治理与取消契约。启用P1时验证两个账号隔离、重复收藏、合并旧ID、跨页导出和保存恢复。

## 12 架构候选与评审项
