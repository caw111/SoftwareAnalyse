## 3 主要冲突及统一结果

| 事项 | Group1 或旧材料 | Group2 或其他材料 | 本版处理及理由 |
| --- | --- | --- | --- |

| 一期成果 | Word SRS说论文完整、其余预留 | 四类最小闭环 | 四类均可采集／导入、检索、维护与统计；论文承担规模 |
| 论文来源 | OpenAlex规模建库，DBLP补充 | Crossref主源／定向实验 | 分职责：Crossref定向题录，OpenAlex规模与主题候选，DBLP专业补充；真实接入另验 |
| 实验事实 | 部分汇报说样本仍待验证 | 记录两实验及40条证据、30条统一样本 | 转录原报告描述，明确原件缺失且本次未复现；不称本次已验证 |
| 分页 | 默认10，最大100 | 默认20 | 默认10，可选10/20/50/100，最大100，文档一致 |
| 查询与机构 | 明确人物ID、同贡献与任意作者机构 | 原查询较简略 | 补人物确认、关系语义和条件连续性，不用当前任职替代署名 |
| 专利实体 | 公开文献／申请／家族分层 | 申请号归并较概括 | 三层分开；授权成果按申请计，文献与家族另列 |
| 项目 | Word SPEC缺项目算法与细节 | 统一类型已有项目 | 增加资助机构+批准号与编号类型、时间、缺编号人工复核 |
| 作者模糊自动合并 | ≥0.95候选自动 | 弱匹配只候选 | 一期采用保守规则；定量评分保留候选，自动关闭至标注集及评审完成 |
| 论文／奖励模糊合并 | ≥0.92／≥0.93自动候选 | 论文DOI与人工复核 | 精确无冲突键为基线，弱匹配先复核；阈值是候选，缺失贡献0，强冲突阻断 |
| 认领含义 | 部分SRS将认领统称门户绑定 | 身份／门户／成果分开 | 三者独立；一账号一本人门户、一门户一有效管理账号，多人贡献可分别关联 |
| 认领状态 | 简图与驳回后复用旧申请 | 完整验证／补充／撤回／终态 | 使用Group2完整生命周期；补充新材料版本，再申请新编号保留旧终态 |
| 采集暂停 | SRS有暂停，图无暂停 | 六状态 | 删除暂停承诺，停止协作确认，终态新任务；确需暂停另整体修订 |
| 采集成功 | 部分方案只指采集／解析 | 有界处理及更新可靠登记 | 阶段结果分开；任务SUCCESS为有界处理完成，公开可见另记，不推进失败窗口水位 |
| 重试耗尽 | 保持FAILED | 一处转STOPPED | 耗尽／不可恢复保留FAILED，显式放弃才STOPPED，区分失败与取消 |
| 统计口径 | 全计数、贡献历史、明细 | 多类型、OA／引用覆盖 | 合并同版集合与类型日期，未知不作0，单位奖不自动归个人 |
| 检索排序 | 文本及复合评分两建议 | BM25字段候选 | 默认文本相关度；两组权重各自保留调优候选，不混叠；复合评分未经验证不默认启用 |
| 创新优先级 | 网络过滤／最短路径 | 可解释相关推荐 | 选网络最短路径与证据作为拟定必交付创新；相关推荐P1；评审确认另存 |
| 性能 | 统计P95≤5秒 | 预聚合统计P95≤3秒 | 采用更严格3秒目标，统一1万条／20并发／预热5分钟；所有目标待实测 |
| 分类 | 本地三级与外部四级混合建议 | 分类与采集范围分开 | 本地目录与外部映射分开、版本可追溯，候选与确认分类分开 |
| 私人能力 | 专题笔记、比较导出 | 原主文未完整覆盖 | P1补入完整权限、恢复与验收，私人资料不因管理员角色公开 |
| 实现选型 | 详细方案有具体技术建议 | 产品与参数待确认 | 保留实现语义和候选，不虚构最终技术选型／负责人／已实现路径 |
