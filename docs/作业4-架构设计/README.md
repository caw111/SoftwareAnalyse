# 作业 4 架构设计

第 9 组 · 1011101011 · 2026-11-15 · v1.0

本次作业把采集、处理、存储、服务和展现组织为五层逻辑架构，说明检索、认领、采集处理的服务协作，以及华为云目标部署。五条架构决策涵盖检索引擎、异步处理、数据库与索引一致性、统计计算和认领事务边界。
