# 桌面角色界面 v0.2.0

## 入口与导航

程序是原生 WPF Windows 应用。登录页和主窗口均默认最大化，保留系统标题栏、拖动、最小化、还原/最大化及关闭行为。登录与注册为两个标签；底部灰色“以访客模式进入”无需账号。服务器地址配置移到登录页的“服务器设置”。令牌仅保存在进程内，退出时撤销服务端会话并回到独立入口。

| 身份 | 探索模块 | 个人或管理模块 |
| --- | --- | --- |
| 访客 | 成果发现、学者门户、数据观察、共著路径 | 个人主页：默认头像、未登录、登录跳转 |
| 科研人员 / 待认证注册账号 | 全部公共页面 | 个人主页、个人成果、我的申请 |
| 管理员 | 独立管理空间 | 成果数据库管理、申请管理、数据统计 |

注册账号在认证通过前仍为 USER；提供个人界面不等于授予科研权限。API 持续实施角色校验与申请归属校验。WPF 内部标签也按身份禁用，不能通过 Ctrl+Tab 切到未授权的管理页；401 会清空私有视图并切回访客导航。

## 个人主页

默认头像为原创灰绿色 SVG。登录后展示姓名、学术门户状态、ORCID、我的网站和关于我；编辑保存到后端数据库。网站输入每行“名称 | https://网址”，保存时校验协议、长度、数量，点击使用 Windows 默认浏览器。ORCID 校验格式和校验位；填写 ORCID 不代表平台已核实其所有权。个人资料更新带版本号，旧版本返回 409，前端保留编辑内容而不覆盖其他窗口的更新。

认证面板从右侧覆盖页面，初始约为窗口宽度的 1/4，小窗口最小 300 DIP；拖动左侧分隔条可调整宽度，Tab 焦点限制在面板内，Escape 或遮罩关闭并恢复焦点。灰色提醒为真正的占位文字，不作为材料提交。机构从服务端机构列表加载。

认证沿用 SRS 权限边界：新注册账号先提交机构身份说明，由管理员审核科研身份；通过后再选独立学者 ID 申请门户管理权。两个阶段在列表中统一归入“门户认证申请”，另有“阶段 / 操作”列区分。机构选择目前走人工审核。TODO：数据库登记机构认证端点后，用户选择并确认才用默认浏览器进入机构自身登录页；浏览器跳转本身不能当作认证成功。

## 成果与申请

个人成果只展示本人已经审核确认的贡献。底部申报入口进入“我的申请”的撰写区；在公共成果详情也可直接带入目标成果。申请页按当前登录人分页加载，类型为“成果申领”或“门户认证申请”，阶段列说明身份核验、门户认领、确认贡献或撤销关联。已终审记录只读；草稿和待补充记录可提交，非终审申请可撤回。重复申请保留输入并提示查看原申请。数据范围下拉框用于检索候选门户/成果，不过滤本人已有申请。

## 管理员

- 成果数据库管理：按关键词、类型、模拟/真实资料检索，分页查看规范记录与来源证据；JSON 批次导入及导入审计记录。
- 申请管理：分页查看申请人、类型、目标、阶段、状态和版本；材料区展示申请标识、时间、审核人、占用到期时间及历史；沿用领取租约和版本校验，审核结论必须填写依据。
- 数据统计：全平台账号、科研人员、成果规模、待审/审核中/已通过申请，成果类型和申请状态分布；注明真实/模拟数量、版本与刷新时间。

导航图标统一 24×24 SVG 源文件、20×20 DIP 显示，全部由嵌入资源直接矢量渲染，无 WebView 或浏览器运行时。源文件位于 frontend/AcademicDesktop/Assets/Navigation；默认头像为 Assets/avatar-default.svg。

## 验证与后续范围

显式 `--smoke` 只读验证公共页面；`--workspace-smoke` 在本机演示 API 新建唯一合成账号、学者与三条申请，串行验证身份→门户→成果审核和三种导航，保留合成记录以便审计，最后撤销测试会话。默认启动不会运行这些验收流程。`--login-smoke` 验证实际登录/注册/访客按钮。测试结果和截图写到 ACADEMIC_SMOKE_OUTPUT 指定位置。

本地不运行压测，性能脚本留待服务器执行。元数据修订/软删除、机构 SSO、自动采集治理和更细的来源质量统计仍是后续项；当前目录继续使用不可变来源和追加发布版本。

最终验证结果、截图和可复现命令见 [v0.2 验收记录](verification/v0.2/README.md)。
