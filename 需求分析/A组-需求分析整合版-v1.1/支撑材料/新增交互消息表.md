## 认领原子授权与撤回竞争

| 消息 | 发送者 → 接收者 | 内容 | 所在分支 |
| --- | --- | --- | --- |
| CX01 | 有权审核人 → ClaimControl | approveClaim(申请、材料版本、expectedVersion) | 主流程 |
| CX02 | ClaimControl → ClaimApplication | 重读申请；仅 PENDING_REVIEW 且版本匹配可继续 | critical [批准事务  账号资格、审核权限、目标版本与双方有效唯一性重验] |
| CX03 | ClaimControl → PortalAuthorization | 复核有效授权：账号最多一个；门户最多一个 | critical [批准事务  账号资格、审核权限、目标版本与双方有效唯一性重验] |
| CX04 | ClaimControl → ClaimApplication | approve(expectedVersion) → APPROVED | critical [批准事务  账号资格、审核权限、目标版本与双方有效唯一性重验]；alt [全部条件成立] |
| CX05 | ClaimControl → PortalAuthorization | 创建指定账号与门户的有效授权 | critical [批准事务  账号资格、审核权限、目标版本与双方有效唯一性重验]；alt [全部条件成立] |
| CX06 | ClaimControl → ReviewRecord／AuditEntry | appendDecision(批准, 理由)；追加审计；共同提交 | critical [批准事务  账号资格、审核权限、目标版本与双方有效唯一性重验]；alt [全部条件成立] |
| CX07 | 申请人 → ClaimControl | withdrawClaim(申请、expectedVersion) | 主流程 |
| CX08 | ClaimControl → ClaimApplication | withdraw(expectedVersion) → WITHDRAWN | critical [撤回事务  校验本人身份、当前状态和预期版本]；alt [PENDING_REVIEW 或 NEED_MORE_INFO 且版本匹配] |
| CX09 | ClaimControl → ReviewRecord／AuditEntry | 追加撤回审计；共同提交，不创建授权 | critical [撤回事务  校验本人身份、当前状态和预期版本]；alt [PENDING_REVIEW 或 NEED_MORE_INFO 且版本匹配] |
| CX10 | ClaimControl → 申请人 | 返回提交结果／版本冲突；同一版本最多一条路径成功 | 主流程 |
| ref | 交互引用 | 通过后解除授权使用 PortalAuthorization.revoke()；保留 APPROVED 和历史 | 主流程 |
