# 六状态与消息对照

依据SRS §4.1.3及指定历史图《数据采集任务状态机.drawio》。

|转换|消息|条件和结果|
|---|---|---|
|创建→PENDING|M03|校验通过创建；固定范围/窗口/版本|
|PENDING→RUNNING|M04—M05|worker可用且未停止；尝试、租约及心跳|
|PENDING→STOPPED|X01—X02|管理员取消，记录原因|
|RUNNING→SUCCEEDED|M15|整窗处理、校验、可靠登记通过；水位一致提交|
|RUNNING→FAILED|M18/X06|错误或超时；保留断点，不推进水位|
|RUNNING→STOPPED|X03—X04|受控取消，在安全边界退出|
|FAILED→RETRYING|X07|预算内且可重试、未停止；计数及退避|
|RETRYING→RUNNING|X08|退避结束、未停止；新有效执行尝试|
|RETRYING→STOPPED|X02|停止，不再调度|
|FAILED→STOPPED|X10|耗尽或人工终止；保留失败历史|

非重试错误保持FAILED等待人工处理；不是自动STOPPED。SUCCEEDED、STOPPED为本次终态，再执行创建新任务。REVIEW_REQUIRED、QUARANTINED、ERROR是处理阶段结果，不是新增采集任务状态。分页断点是已可靠登记页面的恢复位置；成功水位只表示整窗处理已成功，二者分别保存。
