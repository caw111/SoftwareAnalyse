## 第3页｜业务背景与分析范围

- 平台整合论文、专利、科研项目和获奖信息，为学者建立成果展示门户。
- 公众用户检索和查看公开信息；科研人员认领并管理本人门户；管理员负责采集、审核和治理。
- 数据来源包括公共学术数据库及符合要求的公开来源。
- 本次分析重点：业务对象及关系、数据采集入库、门户认领审核、检索请求处理。
- 分析依据：实践任务书、SRS v2.0、SPEC v2.0及需求条目与验收场景。

## 第4页｜业务对象识别

- 识别标准：具有稳定身份、明确职责、独立生命周期或需要持续维护的业务关系。
- 人员与门户：账号、学者、门户、管理授权、认领申请、审核记录。
- 成果与组织：成果、论文、专利、项目、获奖、贡献、机构、学术领域。
- 来源与治理：数据源、来源记录、采集任务、来源映射、更新记录、公开版本。
- 展示按业务领域分组的对象清单，说明对象如何支撑三个关键流程。

## 第6页｜账号、学者、门户与授权的关系

- 账号承担登录和身份认证；学者表示现实中的科研人员。
- 平台可以先采集学者信息并建立门户，此时本人尚未注册或认领。
- 认领申请记录申请人、目标门户、证明材料和审核状态。
- 审核通过后建立门户管理授权；授权关系与具体成果贡献分别维护。
- 展示案例：采集到学者档案 → 本人注册 → 提交认领 → 审核通过 → 获得管理权限。
- 配图：人员、门户和授权关系的类图局部。

## 第7页｜四类成果及贡献关系

- 论文、专利、科研项目和获奖共享成果公共信息，并保留各自专属属性。
- 不同成果使用对应的强标识和日期语义，不能仅按标题去重。
- 专利申请、公开文献和专利家族分别表达，避免混淆身份。
- 贡献关系记录人员或机构参与成果的角色，避免把门户管理权当成果归属。
- 学术领域支持分类管理；机构与贡献关联支撑按机构检索和统计。
- 配图：成果类型、贡献、机构与领域的关键关系局部。

## 第8页｜来源、采集与更新对象

- 数据源描述数据获取渠道；来源记录保存原始内容与版本证据。
- 采集任务记录执行范围、状态和进度，组织数据获取及处理。
- 来源映射连接原始记录与规范成果，支持重复来源追踪。
- 更新记录说明规范数据发生了什么变化及其依据。
- 公开版本表示可对外查询的数据集合，与采集任务完成状态分开管理。
- 配图：数据源 → 来源记录 → 来源映射 → 规范成果，并关联采集任务、更新记录和公开版本。

## 第9页｜数据采集入库时序

- 触发：管理员或既定调度机制启动采集任务。
- 正常路径：获取来源 → 保留原始记录 → 清洗校验 → 去重消歧 → 规范入库 → 记录更新和处理结果。
- 强标识冲突进入复核，弱相似不能直接自动合并；规范成果去重后仍保留来源证据。
- 停止请求在安全边界生效，失效执行轮次不得继续写入或回调成功。
- 分页检查点与完整窗口成功水位分别管理；采集成功不等于已公开发布。
- 展示正式采集时序主图及清洗去重、停止重试关键片段。

## 第10页｜门户认领审核时序

- 前置条件：申请人已登录，目标学者门户已存在。
- 正常路径：提交申请及证明 → 校验 → 管理员审核 → 批准 → 建立授权并记录审计。
- 异常分支：补充材料、驳回、撤回、门户绑定竞争。
- 六状态：DRAFT、PENDING_REVIEW、NEED_MORE_INFO、APPROVED、REJECTED、WITHDRAWN。
- 关键约束：批准、授权和审计保持原子性；并发审核与撤回必须检查当前状态和版本。
- 展示正式认领时序图，突出批准授权与异常分支。

## 第11页｜检索请求处理时序

- 参与者包括匿名访客，检索范围为允许公开访问的学术信息。
- 正常路径：输入条件 → 解析查询 → 检索公开数据 → 权限过滤 → 稳定排序与分页 → 返回结果。
- 组合规则：跨维度AND、同维度OR；人物与机构组合保持同一贡献关系语义。
- 分页、详情与统计明确引用同一公开数据版本，同时执行实时权限规则。
- 无结果、处理错误、超时和版本失效分别表达。
- 展示正式检索时序图，标出公开版本及异常返回的位置。

## 第12页｜需求与模型的对应关系

| 业务需求 | 核心对象 | 模型中的体现 |

| 来源保留与数据更新 | 来源记录、来源映射、采集任务、更新记录 | 采集入库及更新交互 |
| 门户认领与授权管理 | 账号、学者、门户、认领申请、授权 | 校验、审核、授权和审计交互 |
| 公开检索与版本一致性 | 成果、贡献、机构、领域、公开版本 | 筛选、排序、分页、版本与权限处理 |

- 展示追踪链：需求条目 → 对象职责 → 类图/时序 → 检查场景。
- 全局检查：对象术语、接收操作、状态和约束在图与报告中一致。

## 第13页｜典型场景与模型验证

- 同一DOI从两个来源采集：规范成果不重复，原始来源证据保留。
- 采集运行时停止：在安全边界退出，不把未完成窗口记为成功。
- 学者存在但尚未认领：公开门户可以存在，账号尚未取得管理授权。
- 审核批准与撤回同时发生：状态及版本校验防止冲突操作同时成功。
- 检索超时或指定版本失效：返回明确异常，不伪装为空结果或静默切换版本。
- 展示实际走查记录中的“发现问题 → 需求依据 → 修订 → 复验结果”；填写真实结果，说明属于模型逻辑走查。
