# 科研人员个人门户认领审核流程活动图说明

## 1. 用例名称

科研人员申请认领个人门户并完成身份认证。

## 2. 参与者

- 申请人：登录平台，选择待认领的学者门户，提交身份信息和证明材料，并查看申请状态。
- 系统：校验申请材料，检查重复申请，维护申请状态，审核完成后绑定账号与门户并发送通知。
- 管理员：核验申请人与门户资料是否一致，作出通过或驳回决定；驳回时填写理由。

## 3. 前置条件

1. 申请人已注册并登录平台。
2. 平台中已存在申请人拟认领的学者门户资料。
3. 申请人能够提供系统要求的身份或机构证明材料。

## 4. 主流程

1. 申请人进入门户认领功能，选择拟认领的学者门户。
2. 申请人填写身份信息、所属机构并提交证明材料。
3. 系统校验必填信息、材料格式和申请权限。
4. 系统检查同一门户是否已有待审核或已通过的申请。
5. 系统保存有效申请，状态设为“待审核”。
6. 管理员查看申请信息和认证材料，并核验申请人与门户资料。
7. 管理员确认通过后，系统将申请状态更新为“已通过”，赋予科研人员角色，绑定申请人账号与个人门户并通知申请人。
8. 申请人进入个人门户并维护其学术成果。

## 5. 异常与替代流程

- 材料不完整或格式不符合要求：系统返回修改提示，申请人补充或修改后重新提交。
- 同一门户已有待审核或已通过申请：系统提示申请人查看已有申请状态，不再创建重复申请。
- 管理员核验不通过：管理员填写驳回理由，系统将申请状态更新为“已驳回”并通知申请人；申请人查看驳回理由后流程结束。

## 6. 申请状态

```text
提交申请 -> 待审核 -> 已通过
                    \-> 已驳回
```

## 7. 设计依据与范围

活动图依据课程任务书中“门户认领审核流程（提交申请 → 验证 → 审核 → 通过/驳回）”的要求，并结合需求规格说明书中的科研人员身份申请、机构选择和管理员审核规则。此处的“门户认领”指申请人认领代表本人身份的科研人员门户，不是认领单篇论文或其他学术成果。
